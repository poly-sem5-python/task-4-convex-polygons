# task-4-convex-polygons

## Задача

Реализовать класс выпуклых многоугольников на плоскости.

**Операции:**
- Пересечение двух многоугольников
- Проверка нахождения точки внутри многоугольника
- Триангуляция

**Методы:**
- Площадь
- Периметр

**Дополнительно:**
- Проверка выпуклости многоугольника при инициализации из списка вершин

## Структура классов

- `Point` — точка на плоскости (координаты `x`, `y`)
- `ConvexPolygon` — выпуклый многоугольник, хранит список вершин `Point` в порядке обхода
- `NotConvexError` — исключение, если переданные вершины не образуют выпуклый многоугольник

**Вершины доллжны передоваться в конструктор уже в порядке обхода по контуру, так как класс  `ConvexPolygon` не строит выпуклую оболочку из произвольного набора точек, а лишь проверяет, что переданный контур выпуклый.**

## Реализация

1. **Проверка выпуклости** — в `__init__`, через анализ знака векторного произведения соседних рёбер (`_cross`): если все повороты вдоль контура в одну сторону — многоугольник выпуклый, иначе выбрасывается `NotConvexError`
2. **Площадь и периметр** — реализованы как `@property`:
   - `area` — формула Гаусса:

  $$S = \frac{1}{2}\left|\sum_{i=0}^{n-1}(x_i \cdot y_{i+1} - x_{i+1}\cdot y_i)\right|$$

- `perimeter` — сумма длин сторон:

  $$P = \sum_{i=0}^{n-1}\sqrt{(x_{i+1}-x_i)^2 + (y_{i+1}-y_i)^2}$$
3. **Проверка точки внутри** (`contains_point`) — точка внутри выпуклого многоугольника тогда и только тогда, когда она лежит по одну сторону от каждого ребра 
4. **Триангуляция** (`triangulate`) — соединяем первую вершину со всеми остальными, получаем `n - 2` треугольников
5. **Пересечение** (`intersect`) —  последовательное отсечение одного многоугольника по каждой стороне другого

## Как запустить

```sh
python3 convex_polygon.py
```

Файл содержит демонстрацию всех методов на примере квадрата и треугольника.

## Пример использования

```python

square = ConvexPolygon([(0, 0), (4, 0), (4, 4), (0, 4)])

print(square.area)                      # 16.0
print(square.perimeter)                 # 16.0
print(square.contains_point((2, 2)))    # True
print(square.triangulate())             # [(P0,P1,P2), (P0,P2,P3)]

triangle = ConvexPolygon([(2, -2), (6, 2), (2, 6)])
inter = square.intersect(triangle)
print(inter.area if inter else "Нет пересечения")

```
